# Einleitung

> **Hinweis:** Teil des Skripts „Git und Versionskontrolle“, aus der LaTeX-Quelle in Markdown umgewandelt. Die Kapitel zu den Modulen stehen als `skript.md` in den Modulordnern.

Dieses Skript führt Schritt für Schritt von den Grundlagen der Versionskontrolle mit Git bis zum Betrieb in Teams und Unternehmen. Es ist so geschrieben, dass Sie das Thema ohne weitere Quellen von Grund auf verstehen können: Jede Lerneinheit erklärt zuerst in zusammenhängender Prosa, was ein Konzept ist, wozu man es braucht und warum es so gelöst ist. Danach folgen mindestens ein vollständiges Beispiel, das Sie selbst ausführen können, typische Fehler mit Gegenbeispiel und ein Praxisbezug.

### Aufbau.

Das Skript gliedert sich in zwölf Module. Jedes Modul beginnt mit Dauer, Priorität und der Tabelle seiner Lerneinheiten, folgt der Reihenfolge des Lehrplans und endet mit Übungsaufgaben steigender Schwierigkeit samt Lösungen. Die Module wurden nach Priorität erarbeitet: zuerst die Module mit Priorität 1, danach 2 und 3.

### Boxen.

Drei farbige Boxen ergänzen den Text. Die blaue Box *Merke* fasst Kernaussagen zusammen. Die grüne Box *Ergänzung aus der Nachrecherche* kennzeichnet Inhalte, die über den Lehrplan hinausgehen und aus aktuellen Quellen stammen; die Quellen stehen im Quellenverzeichnis. Die orange Box *Praxisbeispiel* zeigt eine Situation aus dem Projektalltag.

### Beispiele ausführen.

Alle Beispiele sind für eine Unix-artige Shell geschrieben (Linux, macOS, Git Bash unter Windows). Jedes Beispiel legt sein eigenes Repository in einem neuen Verzeichnis an; führen Sie es deshalb in einem leeren Übungsordner aus und nicht innerhalb eines bestehenden Projekts. Die Beispiele wurden mit Git 2.43 getestet. Die ausgegebenen Commit-Hashes weichen bei Ihnen ab, weil sie Zeitstempel und Autor enthalten.

### Zum Lehrplan.

In mehreren Modulen weichen die Stundensummen der Lerneinheiten von den Angaben der Modulübersicht ab. Das Skript nennt in jedem betroffenen Modul beide Werte und folgt dem höheren.
